# /shorts — 영상 하나 → 완성 쇼츠 (자동)

사용자는 영상 편집을 모르는 사람일 수 있다. 모든 대화는 한국어, 쉬운 말.
**기본은 묻지 않고 끝까지 간다.** 결정은 정책(`style/policy.json`)과 취향(`style/taste.json` + `projects/<이름>/taste.json`)으로 내리고,
마지막에 **결정 요약 한 번**으로 보여 준다. 사용자는 결과를 보고 고치면 된다 — 고친 내용은 취향으로 기억한다 (`style/README.md`).

```
준비 → ① 영상 → ② 자막 → ③ 말 편집 → ④ 스타일·B-roll → ④-1 스토리보드 → ⑤ 렌더·자체 검수 → 결정 요약
```

## 언제 묻는가 (취향 `ask`)
- `never`(기본): 아래 **멈춤 조건**일 때만 묻는다.
- `important`: 멈춤 조건 + 훅 재배치처럼 내용 순서가 바뀔 때 계획을 한 번 보여 주고 진행. 스토리보드도 한 번 보여 준다.
- `always`: 예전처럼 관문마다 확인.

**멈춤 조건** (이때만 AskUserQuestion — 질문 하나, 추천 옵션 먼저)
1. 영상 파일을 못 찾았거나 후보가 여러 개인데 이름·날짜로도 못 고를 때.
2. 화면에 크게 띄울 고유명사(제품명·사람 이름)가 음성 인식과 대본 어디에도 확실하지 않을 때.
3. 정책끼리 부딪혀 어느 쪽을 어겨야만 할 때 (예: 영상이 전부 10초 넘는 한 문장).
그 밖의 모호함은 아래 **기본 해석**으로 정하고, `projects/<이름>/decisions.md` 에 "무엇을 · 왜 · 바꾸려면" 한 줄씩 적는다.

## 모호함을 줄이는 기본 해석
| 모호한 것 | 이렇게 정한다 |
|---|---|
| 경로가 `.../` 처럼 줄어 있음 | 파일 이름으로 `projects/`, 홈 폴더를 찾는다 (`mdfind -name`, `find`). 하나면 그걸로 |
| 사용자가 대본을 같이 줌 | 대본이 **정답 글자**. 음성 인식은 시간만. 대본과 다르게 들린 곳은 대본을 따른다 |
| 팔레트 | 취향 `look.palette`. `auto` 면 주제로: IT·AI·개발 → darktech, 심리·마케팅·일반 → editorial, 금융·공부·역사 → academic |
| 색(3색·강조색) | 묻지 않는다. `look.triad: auto` 가 영상 배경색에 어울리는 승인 3색을 고른다 (`render --check` 가 ℹ️ 로 후보 3개를 보여 줌) |
| B-roll 양 | 취향 `broll.density`. 영상이 40초 이하면 한 단계 올린다 |
| 무음·군더더기·훅 | 취향 `edit.*` → `viral-edit` 스킬 |
| 템플릿에 없는 표현이 대사에 나옴 ("빛이 번지죠") | 대사가 화면을 설명하면 **그 화면을 보여 줘야** 한다 → `motion-kit` 으로 만든다 (묻지 않음) |
| 짧은 장면이 정책 최소 길이에 걸림 | 옆 문장 쪽으로 늘리고, 안 되면 합치거나 뺀다 |

## 0. 준비
`node_modules` 또는 `.venv` 가 없으면 `npm run setup`. 어느 단계든 도구 오류가 나면 **`npm run doctor`** 를 돌려 ❌ 줄의 안내를 쉬운 말로 전하고, `docs/TROUBLESHOOTING.md` 에서 증상을 찾는다.

## ① 영상
1. `npm run new -- "<영상경로>" [짧은-영문-이름]` → `projects/<이름>/`.
2. `npm run new` 가 `face.py` 로 **머리 위치**(정수리·턱·좌우, 초당 4장)를 재서 `video.json` 에 넣는다. 출력의 "머리 위치" 줄만 확인. "얼굴을 찾지 못했습니다"면 `frames/probe_*.jpg` 를 보고 `faceX`, `faceY` 를 직접 적는다.
3. 주제를 보고 `look.palette` 가 auto 면 `projects/<이름>/taste.json` 에 `{"look": {"palette": "..."}}` 로 정해 둔다.

## ② 자막 → `transcribe-ko`
받아쓰기 → 교정(`script.txt`) → `align.py`. 고친 곳은 결정 요약에 표로.

## ③ 말 편집 → `viral-edit`
`edit.structure` 가 hook-first 면 `edit.json` 을 쓰고, `npm run edit -- <이름>`. 무음 제거는 항상 (정도는 취향).

## ④ 스타일·B-roll → `broll-plan`
- plan.json 을 **원본 시간(words.json)** 으로 쓴다 (render 가 편집본 시간으로 옮긴다).
- `theme` 에는 `palette` 만 적어도 된다. 트라이어드·그라디언트 면·효과음 볼륨·자막 크기는 취향에서 온다.
- 필요한 커스텀 장면은 `motion-kit` 으로 바로 만든다.

## ④-1 스토리보드 → `storyboard`
`npm run storyboard -- <이름>` → 장면마다 대표 프레임 시트 + 지문 표. 연속으로 비슷한 장면(정책 `variety`)과 대사에 안 맞는 그림을 **렌더 전에** 고친다. 시트는 직접 본다.

## ⑤ 렌더·자체 검수 (사용자에게 보여 주기 전에 끝낸다)
1. `npm run render -- <이름> --check` → ❌ 는 전부 고친다 (정책 위반). ⚠️ 는 판단.
2. `npm run render -- <이름> --preview`
3. `npm run look -- projects/<이름>/out/preview.mp4 --plan projects/<이름>/plan.json` → 시트를 **직접 본다**.
   훅(0.5초 칸)이 비었거나 약함 / 글자 잘림·겹침 / 자막과 장면 글자 충돌 / 빈 화면 1초 이상 / 얼굴 가림 / 대비.
   의심 구간은 `npm run still -- <이름> --scene <id>` 또는 `npm run still -- <이름> <원본 초…>` 로 렌더 없이 더 본다. 고치고 다시 미리보기 (최대 3번).
4. `npm run render -- <이름>` → `out/final.mp4`, 최종 시트도 한 번 본다.

## 결정 요약 (마지막 메시지 하나)
- 결과 파일, 길이 (편집 전 → 후)
- 정한 것 표: `| 항목 | 정한 것 | 이유 | 바꾸려면 |` — 팔레트, 무음, 훅, B-roll 양, 커스텀 장면, 자막 교정
- 스토리보드 시트 경로 + 거기서 고친 장면 한 줄
- 검수에서 고친 것 한 줄
- "이 설정을 앞으로 기본으로 쓸까요?" 는 사용자가 무언가를 고쳐 달라고 한 뒤에만 묻는다.

## 수정 요청을 받으면
해당 부분만 고쳐 다시 렌더. 취향에 해당하는 말("자막 더 크게", "무음 덜 잘라")은 `projects/<이름>/taste.json` 에 적는다. 같은 방향 요청이 두 번이면 `style/taste.json` 기본값도 바꾸고 알린다.

## 꼭 지킬 것 (정책)
- **지어내지 않는다**: 말하지 않은 숫자·가격·결과·인용·로고를 화면에 넣지 않는다. 추세는 방향만.
- 자막은 **말한 그대로**(오탈자만 교정). 편집은 자르기·옮기기만.
- 첫 1초(훅)는 얼굴 (cutaway 금지, panel·above·below 는 허용).
- 판·카드·자막은 얼굴(정수리~턱)을 가리지 않는다 (배치는 계산되고, 가리면 render 가 막는다).
- 사용자 원본 파일은 수정·삭제하지 않는다 (`projects/` 안에서만).
