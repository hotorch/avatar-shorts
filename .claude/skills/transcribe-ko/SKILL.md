# 한국어 자막: 받아쓰기 → 추론 교정 → 정렬

원칙: **시간은 음성 인식을 믿고, 글자는 믿지 않는다.** 글자는 Claude 가 문맥으로 바로잡고, `align.py` 가 교정된 글자에 원래 시간을 다시 붙인다.

## 1. 받아쓰기
```bash
npm run transcribe -- <slug> --hint "클로드 코드, 리모션"
```
- 기본 모델 `small`. 발음이 뭉개지거나 전문용어가 많아 오류가 많으면 `--model medium` (느리지만 정확).
- 결과: `words.raw.json`(단어별 시간·확신도), `transcript.txt`(문장 원문). 확신이 낮은 단어 목록이 출력된다 → 교정 1순위.

## 2. 추론 교정 → `script.txt`
**사용자가 대본을 줬으면 대본이 정답 글자다.** 들린 대로와 다르면 대본을 따르고(말하지 않은 문장만 빼고), 대본의 쉼표·마침표로 절을 나눈다.
대본이 없으면 `transcript.txt` 를 읽고 다음만 고친다.
- **소리가 비슷한 오인식**: 컵 편집→컷 편집, 표승인→표 승인, 클로드 코트→클로드 코드, 리모선→리모션
- **띄어쓰기** (한국어 맞춤법 기준), 문장부호 최소한 (?, 쉼표 정도)
- **고유명사·영문 표기**: 사용자가 준 힌트, 영상 주제로 추론. 확실하지 않으면 들린 대로 두고 결정 요약에 적는다. 그 이름을 **화면에 크게 띄울 때만** 묻는다 (`shorts` 멈춤 조건 2).
- 숫자: 말한 형태를 존중하되 읽기 쉬운 표기로 (세 단계 / 3단계 둘 다 OK, 금액·퍼센트는 숫자로)

고치지 **않는** 것: 말투, 어순, 군더더기("사실", "결국")를 빼거나 바꾸기. 자막 = 실제로 한 말.
**"음", "어"** 는 대본에 없어도 transcript 에 잡혔으면 script.txt 에 그대로 둔다 — `edit.py` 가 소리와 자막에서 함께 잘라낸다 (여기서 지우면 소리는 남는다).

### 줄 나누기 (한 줄 = 자막 한 큐)
- 의미 단위(절)로 끊는다. 한 줄 **최대 16~18자**(한글 기준). 넘으면 쉼표·접속어 앞에서 나눈다.
- 표기: `*강조*`(강조색) / `+돈·혜택+`(초록) / `-문제-`(빨강) — 한 줄에 최대 2개, 전체의 1/3 줄 이하.
- `>` 로 시작하는 줄 = big 스타일(훅 첫 줄, 마지막 결론). 전체의 30% 이하.
- `#` 줄은 메모(무시됨).

예시
```
> 여러분, 쇼츠 만들 때
*편집*이 제일 오래 걸리죠?
사실 시간을 잡아먹는 건
컷 편집이 아니라
*자막*이랑 *비롤*입니다
```

## 3. 정렬
```bash
npm run align -- <slug>
```
- 출력: `words.json`(교정 단어+시간), `captions.json`(큐). 글자 일치율 90% 이상이면 정상.
- "시간을 추정한 단어"는 교정으로 글자가 크게 바뀐 단어 — 앞뒤 사이로 보간됐으니 대개 괜찮다.
- 일치율이 70% 미만이면 script.txt 가 실제 말과 다르다(문장 누락·추가). transcript 와 대조해 다시.

## 4. 사용자에게 알리기
바뀐 부분만 표로. 취향 `ask` 가 `always` 일 때만 "이대로 갈까요?" 로 멈추고, 아니면 결정 요약에 넣고 계속 간다.

| 들린 대로 | 고친 것 | 이유 |
|---|---|---|
| 컵 편집 | 컷 편집 | 영상 편집 맥락 |

이후 장면 설계에서는 `words.json` 의 단어 시작 시각을 써서 모션을 **말하는 순간에** 맞춘다.
