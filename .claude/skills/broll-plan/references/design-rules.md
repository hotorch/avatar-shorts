# 디자인 규칙 — 프리미엄 에디토리얼 모션

목표 느낌: **잡지 편집 디자인 + 사실적인 3D 오브젝트 + 섬세한 UI 모션**. 조용하고 정확하며, 요란하지 않다.
이 규칙은 kit 컴포넌트에 이미 들어가 있다. 템플릿을 쓰면 자동으로 지켜지고, 커스텀 장면을 만들 때 이 문서를 기준으로 한다.

## 바탕
- 단색 바탕 + 저대비 **점선 격자**(에디토리얼·다크) 또는 **십자 점선 격자**(아카데믹) + 옅은 종이결.
- 반투명 **대각선은 정확히 2개**. 모든 전경 뒤에서 서로 다른 속도로 아주 천천히 움직이고, 바탕색에서 파생한 저대비 색. 절대 시선의 중심이 되지 않는다. 추가 선 금지. (`<Backdrop/>` 이 처리)
- 필요할 때만: 큰 유기적 모서리 도형(`<Blob/>`), 네 갈래 별(`<Star4/>`), 종이 두 장 콜라주(quote).

## 그라디언트 면 (정책 `gradient`, 취향 `look.surface`)
- 면의 색은 **트라이어드 3색만**: 위는 진한색, 왼쪽 위→오른쪽 아래 사선 경계, 가운데 포인트색, 아래 밝은색 물결 띠, 안쪽 옅은 테두리 음영.
- sRGB 기본 보간(탁한 중간색이 원래 디자인). oklab/oklch 금지. 다른 색 섞기 금지.
- 면 **안쪽**은 움직이지 않는다(일렁임·블룸·글로우 금지). 면 전체의 등장·부유는 모션 규칙대로.
- 글자는 위쪽 진한 영역에만 흰색으로. 주인공 오브젝트의 받침으로 쓰기 좋다 (hero 는 surface=gradient 면 자동).
- 한 장면에 그라디언트 면 1장. 여러 장 겹치지 않는다.

## 구성
- 장면마다 **의미가 분명한 주인공 1개 + 보조 최대 2개**. 매 장면 같은 오브젝트를 반복하지 않는다.
- 주인공은 사실적인 3D 오브젝트(`<Object3D/>`)나 큰 타이포(`<KText/>`), 또는 하나의 UI 도형(`morph`).
- 제어된 비대칭. 중앙 안전 영역에 주요 요소. 세로는 위아래 120px, 가로는 가장자리 60px 비움.

## 색
- **중립 80% / 강조 20%**. 강조색은 한 영상에 하나(팔레트 기본 또는 accent).
- 3D 오브젝트 기본 재질: 밝은 팔레트 = `tint`(강조색 듀오톤), 다크 = `color`. 무채색 `clay`, 콜라주 `halftone` 선택 가능.
- 빨강(problem)·초록(money)은 자막 강조에만. 화면 전체를 물들이지 않는다.

| 팔레트 | 바탕 | 강조 | 어울리는 주제 |
|---|---|---|---|
| editorial | 따뜻한 미색 종이, 점선 격자 | 로열 퍼플 | 심리, 마케팅, 인사이트, 교육 전반 |
| darktech | 차콜, 점선 격자, 청록 | 시안/청록 | IT, AI, 개발, 도구 리뷰 |
| academic | 크림, 십자 점선 격자 | 테라코타 | 금융, 역사, 공부법, 설명형 강의 |

## 타이포
- 한글 기본: 굵고 명료한 산세리프(Pretendard 800~900). 자막: SUIT 700.
- 짧은 강조에만 대비되는 세리프/명조: `*단어*` → 라틴은 Instrument Serif, 한글은 나눔명조.
- big 자막(훅·결론): 학교안심 알림장 + 라틴 Instrument Serif.
- 화면 글자 **1~4어절**. 단어별 마스크 등장(아래에서 솟음), 낮은 불투명도의 대형 배경 글자(`ghost`)는 가끔.
- 가독성이 먼저: 본문 최소 44px(1080 기준), 제목 90~150px.

## 움직임
- 모든 움직임은 **시간의 순수 함수** (`spring`/`interpolate`). CSS transition·animation 금지.
- 도착점에서 **5~10% 오버슈트 후 정지** (`SPRING.pop` ζ≈0.65). 직선·기계적 이동 금지.
- 여러 레이어는 **5~10프레임 간격**으로 등장. 깊이(z)가 다른 레이어는 다른 속도로 부유 → 2.5D 패럴랙스.
- 안정된 뒤에는 느린 부유·미세 회전만. 카메라는 고정 기본, 필요시 아주 느린 밀어 들어가기(켄 번즈 1.08 이하).
- 퇴장: 마지막 0.3초에 마스크·페이드로 빠지고, 다음 장면으로 자연스럽게.
- 금지: 튕기는 바운스 반복, 파티클, 과한 글로우, 핸드헬드 흔들림, 회전하며 날아오기.

## 소리
- 효과음만 (종이 스침, 부드러운 휙, UI 클릭, 가벼운 둔탁음, 공기감). 원본 음성이 주인공이라 배경음악은 넣지 않는다.
- 동작과 정확히 같은 프레임에. 장면당 1~3개, 볼륨은 목소리보다 확실히 작게.
