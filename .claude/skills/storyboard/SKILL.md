# 스토리보드: 렌더 전에 장면을 한눈에

전체 렌더는 몇 분 걸린다. 스토리보드는 장면마다 스틸 한 장이라 30초 안팎이다. **고치는 건 여기서** 끝내고 렌더한다.

## 1. 만들기
```bash
npm run storyboard -- <이름>
```
- `projects/<이름>/out/storyboard.png`: 보는 순서(편집 시간 순)대로 왼쪽 위부터 한 칸씩. 대표 프레임 = 장면이 퇴장하기 직전, 요소가 다 나온 순간.
- `projects/<이름>/storyboard.md`: 장면 지문 표 (`| # | 칸 | 편집 시간 | 원본 시간 | 대사 | 배치 | 모션 | 주인공 | 첫 효과음 | 앞 장면과 같은 축 |`).
- 검사(`render --check`)에서 ❌ 가 나오면 시트는 만들지 않고 표와 ❌ 만 남긴다. ❌ 를 전부 고치고 다시 실행한다.
- ⚠️ "마지막 요소가 장면 끝 0.5초 전에 나와 거의 안 보입니다": 무음을 줄이면 장면 끝이 당겨진다. 그 요소의 시각을 앞 단어로 당기거나(`npm run words`), 다음 장면 `in` 이 허락하면 `out` 을 늘린다. 그 칸의 프레임도 덜 그려진 채로 찍힌다.

## 2. 다양성 정책 (`style/policy.json` → `variety`, 렌더가 막는다)
장면마다 지문 4축을 뽑아 **바로 앞 장면**(사이 얼굴 구간 5초 이하)과 비교한다.
| 축 | 어디서 | 예 |
|---|---|---|
| 배치 | `mode` | above, below, panel, cutaway |
| 모션 | 템플릿이 정한다 (`variety.motion`) | hero=object-pop, keyword=type-reveal, list·steps=stack-build, morph=morph |
| 주인공 | 첫 `object`·`center`·media `src` | bulb, gift, broll/a.mp4 |
| 첫 효과음 | 장면 `sfx` 의 첫 cue | pop, whoosh-soft |

- 같은 축이 **2개 이상**이면 ❌ (취향 `broll.variety: strict` 면 1개만 같아도 ❌).
- **주인공이 같으면** 그것만으로 ❌.
- morph 안에서 같은 `kind` 가 연이어 나오면 ❌ (pill → pill 은 변화가 안 보인다).

### 고치는 순서
눈에 보이는 축부터 바꾼다. **효과음만 바꿔 통과시키지 않는다** (지루함은 그대로다).
1. **모션(템플릿)**: 대사에 맞는 다른 템플릿. 머리 위·아래 카드면 morph ↔ keyword ↔ stat ↔ media.
2. **배치**: 이어지는 설명이면 같은 배치로 묶되 템플릿을 바꾼다. above↔below 를 바로 붙이지 않는다 (아바타가 오르내림).
3. **주인공**: 같은 은유가 이어지면 `references/objects.md` 에서 다른 오브젝트, 또는 오브젝트 없는 타이포.
4. 그래도 안 되면 두 장면을 합치거나, 약한 쪽을 얼굴로 둔다.

## 3. 직접 본다 (표가 못 잡는 것)
시트를 **직접 열어 보고** 아래를 확인한다. 걸리면 plan.json 의 그 장면만 고치고 다시 1.
- 이웃한 칸이 **색·구도·크기**로 비슷해 보이는가 (지문이 달라도 화면이 비슷할 수 있다)
- 칸의 그림이 표의 **대사**와 맞는가 ("빛이 번지죠" → 빛 번짐, `git clone` → 터미널)
- 글자 잘림·겹침, 빈 판, 얼굴(정수리~턱) 가림, 자막과 장면 글자 충돌
- 첫 칸(훅)이 얼굴인가

## 4. 묻는가 (취향 `ask`)
- `never`(기본): 묻지 않는다. 스스로 고치고 ⑤ 렌더로 간다. 결정 요약에 `storyboard.png` 경로와 고친 장면을 한 줄로.
- `important`, `always`: 여기서 **한 번** 시트를 보여 주고 AskUserQuestion (추천: "이대로 렌더"). 고칠 장면을 말하면 그 장면만 고쳐 다시 보여 준다.
- 사용자가 "스토리보드 먼저 보여줘"라고 했으면 `ask` 와 상관없이 여기서 멈춘다.

## 5. 정책을 바꾸자고 하면
"비슷해도 괜찮아" 같은 요청은 정책이라 바로 바꾸지 않는다 → "팀 정책이라 policy.json 을 직접 고치거나, 이번 영상만 예외로 둘까요?" (`style/README.md`). 더 엄격하게는 취향이라 바로 바꾼다: `projects/<이름>/taste.json` 에 `{"broll": {"variety": "strict"}}`.
