# style/ — 정책과 취향

영상 하나를 만들 때 내리는 결정은 전부 둘 중 하나다.

| | **정책** `policy.json` | **취향** `taste.json` |
|---|---|---|
| 뜻 | 어기면 결과물이 **틀린** 것 | 둘 다 맞고, **고르는** 것 |
| 누가 정하나 | 팀·채널 (git 에 올려 공유) | 사람·프로젝트 |
| 어기면 | `render --check` 가 ❌ 로 막는다 | 경고 없음. 기본값일 뿐 |
| Claude 는 | 절대 넘지 않는다 | 이 값으로 **묻지 않고** 결정하고, 사용자가 고치면 내 취향(`style/me.json`, 그 PC 에만)에 기억한다 |
| 예 | 지어내지 않기, 첫 1초 얼굴, 아바타 확대 전환 레시피, 장면 색은 테마에서만, 얼굴(정수리~턱) 가리지 않기, 이웃 장면이 비슷하지 않기, 자막 18자, 그라디언트 레시피, 승인된 3색, 오프라인 폰트 | 팔레트, 그라디언트 면 쓸지, 무음을 얼마나 줄일지, 펀치인, 훅을 앞으로 뺄지, B-roll 양, B-roll 배치 섞기, 컷어웨이 퇴장(둥근 창 / 아바타 확대), 자막 크기 |

적용 순서: **정책(잠김) > plan.json 에 직접 쓴 값 > `projects/<이름>/taste.json` > `style/me.json`(내 취향) > `style/taste.json`**
확인: `node scripts/style.mjs <이름>` (합친 결과와 정책 위반을 보여 준다)

## 어느 쪽인지 가르는 질문 (레퍼런스·요청이 들어올 때)
1. **이걸 어기면 누가 봐도 틀렸나?** (사실 왜곡, 안 읽힘, 깨짐, 브랜드 불일치, 법·플랫폼 위반) → 정책
2. **"항상", "반드시", "~하지 않는다", 수치로 된 한계**인가? → 정책 후보
3. **"이런 느낌이 좋다", 고를 수 있는 선택지** 중 하나인가? → 취향
4. **재사용할 모양·코드**인가? (레이어 레시피, 컴포넌트 구조) → 자산 (`src/kit/`). 그 자산을 *어떻게 만들어야 하는지*는 정책, *언제·얼마나 쓸지*는 취향.
5. 레퍼런스가 **다른 매체용**(정지 UI, 인쇄)이면, 우리 매체(영상)에 맞게 옮기고 바꾼 점을 `$doc` 에 적는다.

### 예: 팔레트 카드 그라디언트 가이드를 들였을 때
| 레퍼런스 항목 | 분류 | 들어간 곳 |
|---|---|---|
| 패널 색은 3색만, 다른 색 섞지 않기 | 정책 | `gradient.colorsFromTriadOnly` |
| 4레이어 + 안쪽 음영 레시피, 좌표·퍼센트 | 자산 + 정책 | `src/kit/Gradient.tsx`, `gradient.recipe` |
| sRGB 보간, oklab 금지 | 정책 | `gradient.interpolation`, `motion.banned` |
| 그라디언트 일렁임·글로우 금지 | 정책 (영상에 맞게: *면 안*은 정지, 면 전체의 등장·부유는 허용) | `gradient.animateInside`, `glow` |
| 로고·핸들은 진한 영역 위 흰색 | 정책 | `gradient.textOnGradient` |
| dark 는 충분히 어둡게, light 는 흰색에 가깝게, accent 는 채도 높게 | 정책 — **레퍼런스 이미지 6장을 보고 수정**: 실제로는 진한색이 파랑(0038BD)·올리브(576238)일 때도 있고 포인트색이 밝은색보다 밝을 때도 있다. 그래서 밝기·채도가 아니라 **글자 대비**로 검사 (흰 로고/진한색 ≥ 4.5, 탭1 포인트색/진한색 ≥ 3, 탭3 진한색/밝은색 ≥ 4.5. 탭2 는 흐린 게 원래 디자인이라 검사 안 함) | `triad.contrast` |
| 팔레트 예시 6벌(가이드) + 레퍼런스 이미지 6벌 | 정책 (승인 목록, 이름은 우리가 새로 붙임) | `triad.approved` (`src: guide / ref / kit`) |
| 레시피가 맞는지 | 검증: 같은 3색으로 렌더해 이미지와 패널 48곳 비교, 평균 ΔE 1.5~3.0 | `gradient.$doc` |
| 겹쳐 쌓인 탭 3장 카드 | 자산 | `PaletteCard`, 템플릿 `palette` |
| Poppins | 정책과 충돌 → 대체 | Pretendard (오프라인 폰트 정책) |
| 핸들 `@HUE.FOLIO`, 로고 마크 | 넣지 않음 | 남의 브랜드 |
| 어느 트라이어드를 쓸지, 그라디언트 면을 쓸지 | 취향 (기본 auto = 영상 배경색에 어울리는 것을 자동으로) | `look.triad`, `look.surface` |

### 예: 모션 레퍼런스 영상 2개를 들였을 때 (avatar-v03)
짧은 모션 클립(4초, 얼굴·말 없음)은 `npm run reference` 숫자(전환 수·쉼·얼굴 비율)가 거의 의미 없다 → **콘택트 시트(초당 6장)를 직접 보고** 움직임을 문장으로 쪼갰다. 사용자가 "이 부분만 좋다"고 한 것만 가져왔다.
| 레퍼런스 항목 | 분류 | 들어간 곳 |
|---|---|---|
| (Scene.mp4) 가운데 작은 사진 틀이 계단식으로 커져 화면을 채움 | 자산 + 정책(만드는 법) + 취향(쓸지) | `AvatarGrow`(`src/layouts/Vertical.tsx`) · 정책 `avatarGrow`(0.8초, 0.2→0.46→1 세 계단, pop, 틀 비율 = 화면 비율, 뒤에 얼굴 1초+) · 취향 `broll.exit` |
| 영상에 맞게 바꾼 점 | — | 사진 대신 **실제 말하는 아바타 영상**. 컷어웨이에서 얼굴로 돌아오는 순간에만 (판·카드 장면은 얼굴이 이미 보여서 제외) |
| (Scene.mp4) 굵은 표지 타이포·모서리 라벨 | 넣지 않음 | 사용자: "타이포는 내 취향 아님" |
| (savee) 세로로 쌓인 띠 중 가운데 한 장만 펼쳐지고 넘길 때마다 바뀜 | 자산 | 커스텀 장면 `StackCarousel` (종류 3~5개를 차례로 말할 때, cutaway) |
| (savee) 바탕색이 그림 색을 따라 바뀜 | 정책과 충돌 → 대체 | 트라이어드 색을 따라감 (정책 `sceneColors`) |
| (둘 다) 단색 면, 그라디언트 없음 | 취향 (이 PC) | `style/me.json` `look.surface=flat` |
| 사진·로고·브랜드 글자(ACME, SAVEE) | 넣지 않음 | 남의 그림·브랜드 |

## 취향이 학습되는 방식
`style/taste.json` 은 팀·채널이 git 으로 나누는 **공용 기본값**이고, 한 사람의 취향은 **`style/me.json`** (그 사람 PC 에만, git 제외) 에 쌓인다. 볼 때는 `npm run me`.

사용자가 결과를 보고 "자막 더 크게", "무음 덜 자르게", "그라디언트 빼 줘" 라고 하면:
1. 이번 프로젝트는 `projects/<이름>/taste.json` 에 적는다.
2. 한 번 더 같은 방향으로 고치면(또는 "앞으로도") 내 취향에 적고 한 줄로 알린다: `npm run me -- --set captions.scale=1.2 --why "자막 더 크게 (두 번)"`.

좋아하는 영상을 주면 (`reference-taste` 스킬, `npm run reference -- <영상>`) 화면 전환 리듬·말 사이 쉼·밝기를 재서 `broll.density`·`edit.silence`·`look.palette` 를 계산하고(레퍼런스가 여럿이면 중앙값), Claude 가 시트를 보고 자막 크기·배치·면을 정한다. 사용자가 직접 고친 값이 레퍼런스 계산보다 이긴다.

공용 기본값(`style/taste.json`)은 팀이 "이걸 모두의 기본으로" 라고 할 때만 바꾼다 (`style-intake`).
정책은 사용자 한 명의 말로 바꾸지 않는다. 바꾸자고 하면 "팀 정책이라 policy.json 을 직접 고치거나, 이번 영상만 예외로 둘까요?" 로 묻는다.

## 취향 값
| 키 | 값 | 뜻 |
|---|---|---|
| `ask` | `never` / `important` / `always` | 질문 정도. never = 끝까지 알아서, 마지막에 결정 요약만 |
| `look.palette` | `auto` / `darktech` / `editorial` / `academic` | auto = 주제로 Claude 가 고름 (IT·AI → darktech, 심리·마케팅 → editorial, 금융·공부 → academic) |
| `look.triad` | `auto` / 승인 목록 이름 / `["#dark","#accent","#light"]` | auto = 영상 배경(얼굴 제외)의 색상 분포와 포인트색·진한색 색상이 가까운 승인 트라이어드 (`video.json tones`, 정책 `triad.auto`). 배경이 무채색이면 팔레트 기본. 직접 주면 대비 검사를 통과해야 한다. 고른 포인트색이 영상 전체 강조색이 된다(장면 바탕에서 대비 < 3 이면 글자엔 팔레트 강조색) |
| `look.surface` | `gradient` / `flat` | 주인공 면(hero 배경 카드, 빛 번짐 카드)에 그라디언트 |
| `edit.silence` | `tight` / `natural` / `off` | 남길 무음 0.16s / 0.30s / 정책 한계(0.45s)까지만 |
| `edit.fillers` | `true` / `false` | "음", "어" 빼기 (정책 `edit.fillers` 목록) |
| `edit.punchIn` | `true` / `false` | 튄 컷마다 얼굴 기준 1.00↔1.08 줌 (1.5초 간격 이상) |
| `edit.structure` | `hook-first` / `as-is` | 가장 센 문장을 맨 앞으로 (`viral-edit` 스킬) |
| `edit.maxLength` | 초 | 넘으면 덜 중요한 문장부터 뺀다 |
| `broll.density` | `low` / `medium` / `high` | 분당 2~4 / 4~7 / 대부분 |
| `broll.variety` | `normal` / `strict` | 이웃 장면 지문(배치·모션·주인공·첫 효과음)에서 같아도 되는 축 수. normal = 정책 한계(1개), strict = 0개(전부 달라야). 정책보다 느슨하게는 못 한다 |
| `broll.exit` | `wipe` / `avatar-grow` | 컷어웨이(화면 전체)에서 얼굴로 돌아올 때. wipe = 둥근 창이 닫힘, avatar-grow = 가운데 작은 아바타 틀이 3계단으로 확 커져 꽉 찬 얼굴로 이어짐 (바로 뒤가 다른 장면이면 wipe) |
| `broll.framing` | `varied` / `split` | varied = 머리 위 카드·턱 아래 카드·분할·전체를 섞는다, split = 분할·전체만 (예전 방식). 어느 쪽이든 얼굴은 가리지 않는다(정책 `face`) |
| `captions.scale` | 0.8 ~ 1.3 | 자막 크기 |
| `sound.sfxVolume` | 0 ~ 1 | 효과음 |
